ROAI – Polymorphic Code Analysis Engine
Overview-
This project demonstrates the limitations of traditional signature-based detection mechanisms and highlights the growing need for behavior-based analysis in modern cybersecurity systems.

Research Goals
Automated Mutation: Using Gemini API to generate unique C++ logic for each build
Hash Variation Study: Demonstrating how SHA-256 signatures change with AI-generated code
Defensive Insights: Highlighting the need for behavior-based security systems (EDR/XDR) over traditional antivirus solutions
Tech Stack
Python (Orchestration)
C++ (Code Logic)
Google Gemini API
MinGW-w64 (Compiler)
Disclaimer

This project is intended for educational and defensive research purposes only. It aims to study detection limitations and support the development of stronger cybersecurity defenses.
